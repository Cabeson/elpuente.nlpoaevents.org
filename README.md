# elpuente.nlpoaevents.org

El Puente: the 2026 NLPOA Omaha National Training Conference & Convention, in pictures.

A page-turning photo magazine with 468 photos in 14 chapters, each opened by a one-page story. It is a static site: `index.html` plus the `img/` folder. There is no build step.

- Turn pages by dragging a corner, swiping, clicking the arrows, or pressing the arrow keys.
- The page-flip effect uses [page-flip](https://www.npmjs.com/package/page-flip) 2.0.7, loaded from jsDelivr.
- `CNAME` points GitHub Pages at `elpuente.nlpoaevents.org`.
